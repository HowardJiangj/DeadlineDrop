How it works

Paste text, extract deadlines, then review each title, date and time. Select the events you want and import the downloaded .ics file into your calendar.

Use a month name or YYYY-MM-DD for clarity. A missing year uses the next occurrence, including today. Ambiguous numeric dates need manual review. Times use the local clock in the importing calendar. Keep dates all-day when no time is specified.
