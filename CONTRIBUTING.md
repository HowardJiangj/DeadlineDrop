# Contributing to DeadlineDrop

Start the preview with `npm start` on Node.js 20 or later. Try the sample announcement and export a calendar before editing.

For a parsing change, add a short invented announcement to the tests. Cover a successful match and a similar expression that should require review. Avoid including real student emails or personal information in reports.

Keep browser modules dependency-free and asset paths relative so the site works under a GitHub Pages project path. For a UI change, check keyboard navigation, narrow screens, and both themes. For an export change, inspect the downloaded file and test an import into a calendar you use.

Run `npm test`, then open a pull request describing the user-visible change and checks you ran. Include a screenshot for layout changes. Contributions use the project's MIT license.
